# WALL-E Campus Assistant

## 1. Project Overview

WALL-E Campus Assistant is a smart robot designed to assist students and faculty members inside the university campus.

The robot provides an interactive touch interface that helps users navigate the campus, manage attendance, and communicate with faculty members through a modern and user-friendly experience.

The project consists of a robot interface, a mobile application, a backend server, and a centralized database.

---

## 2. Objectives

The main objectives of the project are:

- Improve students' navigation inside the university.
- Digitize the attendance process using QR Codes.
- Provide a secure admin authentication system.
- Offer an interactive robot experience.
- Build a scalable software architecture that can be expanded in the future.

---

## 3. System Actors

Student

- Login
- Scan QR Code
- View Attendance History
- View Campus Map
- Search for Classroom
- Receive Navigation Instructions


Admin

- Login
- Face Recognition Authentication
- View Attendance
- Search Students
- Generate Reports
- Manage QR Sessions
- View Statistics


Robot

- Display QR Code
- Show Campus Map
- Play Voice Messages
- Navigate Users
- Receive Commands
- Display Announcements


Backend

- Authentication

- QR Validation

- Attendance Management

- Database Access

- Face Recognition Service

- Notifications
